# 📝 Simple To-Do List (In-Memory)

A simple, responsive To-Do List web application built using HTML, CSS, and JavaScript.

## ✨ Features

- Add new tasks using an input field.
- Display tasks from a JavaScript array.
- Delete individual tasks.
- Update the task list whenever it changes.
- Show the number of tasks.
- Display a message when the list is empty.
- Responsive design for mobile and desktop.
- Tasks are stored in memory only and are not saved after a page refresh.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📁 Project Structure

- `index.html` — Page structure
- `style.css` — Styling and responsive design
- `script.js` — Task array, DOM rendering, and event handling

## 🚀 How to Use

1. Enter a task in the input field.
2. Click **Add Task** to add it to the list.
3. Click **Delete** beside a task to remove it.
4. Refresh the page to see that in-memory tasks are not retained.
